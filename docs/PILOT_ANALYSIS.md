## 6. 五条结论

1. n=10 的置信区间约 ±30 个点，**除 prompt 修复带来的 En.MC/Code.Debug 跃升外，任务间比较都不成立**。
2. 在四个检索类任务上，**模型（90/70/90/50）低于三行正则（均 100）**；其余任务正则=0 是因为没写对应规则，不代表任务不可解。
3. En.Sum 的 20 条低分全部是“内容对、ROUGE 低”，应作为指标问题单列，不计入模型能力。
4. 缓存命中整体仅 4.6%，只有 code_run（44%）明显；其余任务按标价计费，大规模预算不能指望缓存打折。
5. F5 里混着判分 bug（多答案未拆分）与输出不完整，修规则后可把“其他”从 25.6% 压到 10% 以下。
